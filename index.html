case_002 · open source
A bug in the benchmark
While checking my labels I found that AgentDojo, a widely used AI-agent security benchmark, can count a successful data theft as a failed attack.

      

        

          ● issue #245
          
Data theft scored as "failed"

          
Tool outputs reach the model as YAML, which turns I'm into I''m and wraps long lines. The agent forwards the email exactly as it saw it, the exact-match check fails, and the theft goes uncounted. 23 of 31 default emails are affected.

          Read the issue →
          ● pull request #246 · under review
          
My fix ships as a new benchmark version, v1.2.3, so older results stay comparable. It covers five injection tasks and adds 13 tests.

          View the pull request →
